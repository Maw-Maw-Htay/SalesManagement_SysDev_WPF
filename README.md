# SalesManagement_SysDev

電子機器卸売業向けの販売・在庫管理デスクトップアプリケーションです。現在は `SalesManagement_SysDev` プロジェクトへ統合され、ログイン、メインメニュー、商品・顧客検索、受注登録、受注管理、受注詳細、在庫・出荷関連の業務画面を提供します。

## 起動方法

1. Visual Studio 2022 で `SalesManagement_SysDev.sln` を開く。
2. `SalesManagement_SysDev` をスタートアッププロジェクトにする。
3. LocalDB が利用できる状態で起動する。
ログイン画面にはデータベース作成・サンプルデータ登録の操作ボタンはありません。起動時に既存の SQL Server LocalDB SalesManagement への接続を準備し、接続に失敗した場合はログイン画面のボタンから再試行できます。
「パスワードを表示」で入力内容を確認できます。ログイン画面の「パスワード変更」から、社員IDと現在のパスワードを確認して新しいパスワードへ変更できます。変更後は新しいパスワードがログイン欄に入力されます。

データベースは既存の SQL Server LocalDB `SalesManagement` を利用します。接続先や既存データを変更する場合は、担当者の合意を得てから行ってください。

架空の関西OA機器販売株式会社を使うデモは、別プロセスから `SalesManagement_Demo` に接続できます。デモの起動方法、データ構成、検証結果は [デモデータベースの手順](docs/demo-database/README.md) を参照してください。

### ログイン画面で接続を再試行と表示される場合

`接続を確認できませんでした。` と表示された場合は、このPCのLocalDBが起動しているか確認してください。WindowsのPowerShellで次のコマンドを実行します。

```powershell
SqlLocalDB info MSSQLLocalDB
SqlLocalDB start MSSQLLocalDB
```

`Running` または起動成功を確認したら、ログイン画面の「接続を再試行」を押してください。再試行ではこのデータベースの接続プールをリセットし、以前の接続失敗を再利用せず、新しい接続で確認します。LocalDBへのアクセスやプロセス起動が制限された実行環境では起動に失敗する場合があるため、アプリは通常のWindows環境またはVisual Studioから起動してください。起動後も同じエラーが続く場合は、アプリを閉じて再起動し、Windowsのアプリケーションイベントログにある `SQLLocalDB` のエラーを確認してください。

## 主な操作

- 営業担当者は顧客・商品を選択して受注を登録できます。数量は直接入力または＋／−で変更し、明細の金額・税・合計へ即時反映します。商品詳細・実在庫の不足警告・明細削除後6秒間のUndoに対応します。在庫不足だけでは登録を止めず、在庫を減算しません。
- 受注管理では淡色テーマの一覧を使い、白い上部ヘッダーから受注を登録できます。クイック検索は受注番号・顧客ID・顧客名に対応し、折りたたみ式の詳細条件では受注番号、顧客ID／顧客名、担当者、受付営業所、受注日、納期を組み合わせて絞り込めます。状態タブは独立して選択でき、検索結果の件数と選択件数を一覧ヘッダーに表示します。
- 受注一覧では商品数、担当者・営業所、税込合計を確認できます。見出しや昇順・降順ボタンで並べ替え、下部でページと表示件数を切り替えられます。
- 状態タブは「すべて」「未確定」「確定済み」「下書き」「非表示」「受注履歴」の順です。「すべて」の件数は表示中の未確定と確定済みの合計です。
- 状態タブ列の右側にある「CSV取込」で、`外部受注番号,受注日,納期,営業所ID,担当者ID,顧客ID,商品ID,数量,単価` のCSVを検証・プレビューし、確認後に取り込めます。同じ外部受注番号の明細行は1件の受注にまとめます。`納期` は空欄可です。「印刷」では現在の検索・タブ条件に一致する登録済み受注を、画面の並び順と税込額でA4横向きにプレビューします。
- 受注一覧から受注詳細を開き、受注確定、非表示、明細確認を行えます。
- 受注詳細の「伝票印刷」は確定済みの選択受注1件をDBから再取得し、顧客・受注・商品明細と税額を含むA4縦プレビューを表示します。「印刷」から Microsoft Print to PDF を選べます。受注一覧の絞り込み印刷とは別の機能です。
- 非表示は専用ダイアログで対象番号・選択件数を確認し、理由を入力して実行します。一括処理は成功・失敗を個別に表示し、検索条件とタブを保持して一覧・件数を更新します。
- 未確定の受注詳細では、備考・数量を更新できます。単価は参照専用です。確定済みまたは非表示の受注は更新できません。
- 在庫管理では在庫数・商品マスタの安全在庫を使った在庫状態を確認し、商品コード・商品名・メーカー・分類・数量で絞り込めます。在庫数の更新は注文・入出庫など既存の業務処理で行い、一覧から直接変更しません。
- 受注管理から受注登録ページへ移動し、登録後は完了ダイアログから一覧または保存済みの受注詳細へ移動できます。
- 受注登録ではメーカーと商品コード・商品名・バーコードを組み合わせて商品候補を絞り込めます。候補にはメーカー・在庫数・単価を表示します。
- 入力途中の受注は、画面下部の「一時的保存」で SQL Server に保存できます。「下書き」タブでは自分の下書きを検索し、行をダブルクリックするか「⋯」から開けます。「⋯」から削除もできます。正式登録すると未確定受注が1件作成され、下書き一覧から消えます。未保存の変更がある場合は、移動前に入力継続・一時保存・破棄を選べます。
- ログインユーザーの権限と営業所範囲に応じて操作できる画面とデータが変わります。
- 「顧客管理」では顧客ID・顧客名・電話番号で検索し、詳細条件で絞り込めます。顧客詳細から、権限に応じて関連受注を参照専用で開けます。非表示と復元は顧客の表示状態だけを変更します。
- 「商品管理」では商品コード・商品名・カテゴリを検索できます。商品詳細から現在庫と関連受注明細を参照できます。商品マスタの編集は現在庫や保存済みの取引金額を変更しません。
- 管理者は全業務画面、物流担当は商品・在庫・出庫・発注・入庫、営業担当は顧客・受注・注文・入荷・出荷・売上を利用できます。
- 「ログイン管理」から現在のパスワードを確認したうえで変更できます。新しいパスワードは半角英数字4～10文字で、確認欄との一致が必要です。入力条件を満たすと変更ボタンが有効になります。
- 管理者は「社員管理」で社員番号・社員名・ログインIDを検索できます。詳細条件と組み合わせて絞り込めます。一覧は初期20件ずつ表示し、「すべて」「表示中」「非表示」に実件数を表示します。
- ヘッダーの「社員登録」から社員を登録できます。登録完了時に社員番号とログインIDを表示します。社員詳細から編集、所属・権限の変更履歴の参照、理由を入力してログインを無効化する操作ができます。「権限管理」は現在のロールの参照専用です。
- 「売上管理」では許可営業所内の売上一覧、検索、保存済み明細の参照、管理者による理由付き非表示を行えます。売上合計・件数・平均は当月の表示中レコードを対象に、売上明細へ保存済みの金額から算出します。
- 「発注管理」は管理者・物流担当が利用できます。新規発注を登録し、発注詳細の「発注確定」を選ぶと、入庫管理の「入庫待ち」に表示されます。在庫が増えるのは入庫を確定した時です。入庫済数量は棚入れ確定済みの明細から集計します。管理者は理由を入力して発注を非表示にできます。
- 旧版で登録した表示中の発注も、関連入庫がなければ「発注未確定」から発注詳細の「発注確定」で入庫管理に引き継げます。確定時に仕入先と商品を再照合します。
- 「入庫管理」では、入庫待ちの発注を選び、「入庫確認」で実際の入庫日と全商品の入庫数量を入力します。全商品が発注数量と一致すると、入庫実績と商品単位の在庫を同一トランザクションで保存します。在庫管理を開くと最新残高を表示します。「入庫履歴」は確定済み記録の参照専用です。管理者は確定済みの入庫を理由付きで非表示にし、理由が記録されたものを復元できます。
- 「出庫管理」は管理者・物流担当が利用できます。出庫番号・注文番号・営業所・顧客・商品・日付・担当者・出庫状況で検索し、詳細確認、出庫確定、管理者による理由必須の非表示に対応します。注文確定時に在庫は減算済みのため出庫確定では再減算せず、対応する未確定の入荷情報と明細を出庫状態の更新と同じトランザクションで作成します。出庫非表示では入荷・注文・在庫を変更しません。
- 現行DBの入庫・在庫スキーマには倉庫別在庫列と棚入れ確定日時列がなく、在庫は商品単位で管理されます。入庫確定では既存スキーマの在庫を更新し、倉庫別在庫としては表示しません。出庫には既存の担当者列で確定者を記録できます。入荷テーブルには出庫ID列がないため、出庫確定時は注文・顧客・営業所の組み合わせをロックして既存の入荷を確認し、重複作成を防ぎます。直接IDの永続的な参照制約を追加する場合は、別途DB変更の合意が必要です。
- 既存の発注DBには仕入単価、発注金額、納品予定日、標準発注量がないため、これらは表示・計算しません。在庫パネルは現在庫数と商品マスタの安全在庫数を参照するだけです。

## サンプルデータ

起動時にログイン用アカウントと最低限の業務マスタを準備します。大量の画面確認用サンプルデータを登録する操作はログイン画面にありません。
